# ScreenGlow 1.1.0

## What’s new

- Added a short animated launch screen with a reduced-motion friendly presentation.
- Updated the README with the feature list and launch kit.
- Added ready-to-adapt product descriptions, launch posts, and a demo outline in `LAUNCH_KIT.md`.

## Requirements and permissions

- macOS 14 or later
- Screen Recording permission for screen color sampling
- Bluetooth permission and a nearby Lotus Lantern strip for strip control
- Apple Home Matter sharing setup for Matter bulb control

This download is locally signed and not notarized, so macOS may show a Gatekeeper warning the first time you open it.
