# ScreenGlow launch kit

## Short description

ScreenGlow brings the colors on your Mac display into your room. It syncs Lotus Lantern RGB strips and Apple Home Matter bulbs with screen colors, with optional bass-reactive brightness changes for a more immersive setup.

## Store or website description

Make movies, music, and games feel bigger with lighting that follows your Mac. ScreenGlow samples the display and sends changing colors to compatible Lotus Lantern RGB strips and Apple Home Matter bulbs. Use the color palette for a fixed look, adjust screen-sync brightness, and let dark scenes dim the lights. Matter bulbs can also react to bass while screen sync is active.

ScreenGlow runs locally on macOS. It requires macOS 14 or later. Screen sync requires Screen Recording permission; Lotus Lantern strips require Bluetooth. Matter bulbs must be shared with the Mac through Apple Home’s Matter pairing flow.

## Monetization direction

Keep the current core experience free while gathering compatibility and setup feedback. If users return and ask for more, test a one-time purchase for clearly defined advanced features, while keeping basic screen sync usable. A tip link is another low-friction option. Don’t promise a paid tier until the feature set and support expectations are ready.

## Distribution note

The current v1.0.0 download is locally signed and not notarized. That can cause a Gatekeeper warning on first launch. Before promoting widely or charging, create a Developer ID-signed and notarized build, then update the release download and installation instructions.
